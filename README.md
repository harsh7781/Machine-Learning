## 📌 Project Overview
This repository is a comprehensive collection of various **Machine Learning algorithms** implemented using **Python** and **Jupyter Notebooks**. It covers fundamental concepts ranging from regression and classification to clustering and dimensionality reduction.

The project is designed for educational purposes, providing clear code examples created primarily using Google Colaboratory.

---

## 📂 Repository Contents

### 🤖 Supervised Learning
* **Regression:**
    * `linear_regression.ipynb`: Implementation of Linear Regression.
    * `regression_metrics.ipynb`: Evaluation metrics for regression models.
* **Classification:**
    * `knn.ipynb`: K-Nearest Neighbors implementation.
    * `decision_tree.ipynb` & `decision_tree_depth.ipynb`: Decision Tree classifiers and depth analysis.
    * `gaussian_naive_bayes.ipynb`: Naive Bayes implementation.
    * `classification_metrics.ipynb`: Accuracy, Precision, Recall, and F1-Score analysis.

### 🔍 Unsupervised Learning
* **Clustering:**
    * `k_means_clustering_3.ipynb` & `k_means_clustering_5.ipynb`: K-Means implementations.
    * `hierarchical_2.ipynb` & `Hierarchical_clusters_3.ipynb`: Hierarchical clustering techniques.
* **Dimensionality Reduction:**
    * `PCA_using_formula.ipynb`: Principal Component Analysis from scratch.
    * `PCA_using_SKLearn.ipynb`: PCA implementation using Scikit-Learn.

## 🛠️ Prerequisites
To run these notebooks locally, you will need:
* Python 3.x
* Jupyter Notebook or JupyterLab
* Libraries: `numpy`, `pandas`, `matplotlib`, `seaborn`, `scikit-learn`

---

## ⚙️ Installation & Setup
1. **Clone the repository:**
   ```bash
   git clone [https://github.com/harsh7781/Machine-Learning.git](https://github.com/harsh7781/Machine-Learning.git)
   cd Machine-Learning
   ```
2. **Install required dependencies:**
   ```bash
   pip install numpy pandas matplotlib seaborn scikit-learn notebook
   ```
3. **Launch Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```

## 🚀 How to Use
